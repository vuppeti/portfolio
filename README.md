# Developer Portfolio

A modern, production-ready developer portfolio built with React, TypeScript, Vite, TailwindCSS, Framer Motion, and React Router.

## Folder structure

- src/components/layout
- src/components/sections
- src/components/ui
- src/data
- src/pages
- src/assets
- src/styles

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages deployment

1. Update the repository URL in the Vite base config if needed.
2. Run:

```bash
npm run deploy
```

3. In GitHub, open the repository settings and enable GitHub Pages for the `gh-pages` branch.
